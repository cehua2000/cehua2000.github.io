Anthropic

Anthropic三张底牌全翻：Opus 4.8 + Sonnet 4.8 + Mythos 1 同日曝光

在几乎同一天，Anthropic三大超级AI模型信息密集曝光，震撼业界：

① Claude Opus 4.8：在Google Vertex AI平台后台模型列表中被开发者意外发现，模型标识为claude-opus-4.8。Anthropic此前Opus 4.6和4.7均是先在此泄露再正式发布，社区预测约一个月内将正式上线。Opus 4.7曾在基准测试中击败Gemini 3.1 Pro和GPT-5.4。

② Claude Sonnet 4.8：3月31日Anthropic推送Claude Code npm更新时因.npmignore遗漏，导致59.8MB、51.2万行TypeScript源码泄露至npm公共仓库。代码确认将直接从Sonnet 4.6跳过4.7版本，新增"X high"推理层级（不显著增加生成时间但增强推理），预计6月中旬发布。需要注意：新版分词器Token消耗将增加约30%。

③ Mythos 1：曾被称为"太危险不公开"的安全专用模型，在AI测试平台TestingCatalog中被用户短暂看到后又消失，模型标识claude-mythos-1-preview。Anthropic首份报告披露Mythos已在一个月内揪出10,000万个高危漏洞。项目路线图显示将分"Claude Code + Mythos"和"Claude Security + Mythos"双线商业化。

清华

面壁智能×清华大学：中国首个1.58-bit大模型 BitCPM-CANN 发布

面壁智能联合清华大学与OpenBMB开源社区，发布基于华为昇腾训练平台的中国首个三值（1.58-bit）量化大模型BitCPM-CANN。该模型采用全链路原生低比特开发方式，推出0.5B至8B四个尺寸版本，覆盖从端侧到服务器端的完整应用场景。

📌 技术意义：1.58-bit量化意味着模型权重仅需3个值（-1, 0, 1），推理时近乎纯加法运算，功耗和延迟大幅降低。此次基于国产昇腾硬件实现全链路训练，标志着我国在低比特高效推理这一关键赛道取得世界级突破。

🌍 开源生态：以OpenBMB社区为中心全面开源，推动低比特大模型技术的产学研一体化发展。
